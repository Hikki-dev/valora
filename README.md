# Valora 💎

**Valora** is a premium, high-performance game collection valuation tracker. Built with Flutter and powered by Supabase, it helps collectors monitor their physical and digital assets with real-time market data across all major gaming platforms.

---

## 🚀 Key Features

- **Multi-Platform Tracking**: Support for PlayStation, Xbox, Nintendo, Steam, and Epic Games.
- **Real-Time Valuation**: Automated market value lookups using integrated edge functions.
- **Three-Tier Responsive UI**: Optimized layouts for Mobile, Tablet, and Desktop users.
- **WASM Acceleration**: High-speed web performance via WebAssembly.
- **Social Snapshots**: Generate and share beautiful valuation summaries of your "Crown Jewels".
- **Barcode Scanning**: Rapidly add physical titles with UPC/EAN scanning.
- **Steam Sync**: Import your digital library with a single tap.

## 🛠️ Tech Stack

- **Frontend**: Flutter (Riverpod, GoRouter, Animate)
- **Backend**: Supabase (PostgreSQL, Auth, Edge Functions, RLS)
- **Hosting**: Vercel (Web / WASM)
- **Monitoring**: Performance optimized with custom image caching layers.

## 📦 Getting Started

1. **Clone & Install**:
   ```bash
   git clone https://github.com/Hikki-dev/valora.git
   cd valora
   flutter pub get
   ```

2. **Configure Environment**:
   Ensure you have a `.env` file with `SUPABASE_URL` and `SUPABASE_ANON_KEY`.

3. **Run**:
   ```bash
   flutter run
   ```
